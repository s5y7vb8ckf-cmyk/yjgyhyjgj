# نظام فورد V9 – كراون فكتوريا 2010

مشروع Android كامل مع صورة سيارة فضية بتأثير ثلاثي الأبعاد **ثابتة** ومضمنة داخل التطبيق، وليست مجسمًا قابلاً للدوران.

## البناء
ارفع محتويات المجلد (وليس المجلد نفسه) إلى جذر مستودع GitHub ثم افتح Actions وانتظر ملف Ford-Drive-V9-Car-APK.

## ملاحظات
عداد السرعة يعتمد على GPS بعد منح إذن الموقع. قراءة الوقود وحرارة المحرك الحقيقية تتطلب ربط السيارة ولا ينبغي عرض قيم تجريبية على أنها حقيقية.


V12: صورة ثلاثية الأبعاد ثابتة لسيارة كراون فكتوريا فضية بخلفية شفافة حقيقية WebP alpha، مدمجة في assets وخفيفة على شاشة 4GB RAM.
